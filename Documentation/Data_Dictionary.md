# Data Dictionary

This document describes the columns used in the `CLEAN_ENERGY_DATA` table.

| Column | Data Type | Description |
|---------|-----------|-------------|
| COUNTRY | STRING | Country or region name |
| ISO_CODE | STRING | ISO 3166-1 alpha-3 country code |
| YEAR | INTEGER | Observation year |
| POPULATION | NUMBER | Total population |
| GDP | FLOAT | Gross Domestic Product (constant USD) |
| PRIMARY_ENERGY_CONSUMPTION | FLOAT | Total primary energy consumption (TWh) |
| ENERGY_PER_CAPITA | FLOAT | Energy consumption per person |
| ELECTRICITY_GENERATION | FLOAT | Total electricity generated (TWh) |
| ELECTRICITY_DEMAND | FLOAT | Total electricity demand (TWh) |
| COAL_CONSUMPTION | FLOAT | Coal consumption (TWh) |
| OIL_CONSUMPTION | FLOAT | Oil consumption (TWh) |
| GAS_CONSUMPTION | FLOAT | Natural gas consumption (TWh) |
| SOLAR_CONSUMPTION | FLOAT | Solar energy consumption (TWh) |
| WIND_CONSUMPTION | FLOAT | Wind energy consumption (TWh) |
| HYDRO_CONSUMPTION | FLOAT | Hydroelectric energy consumption (TWh) |
| NUCLEAR_CONSUMPTION | FLOAT | Nuclear energy consumption (TWh) |
| RENEWABLES_CONSUMPTION | FLOAT | Total renewable energy consumption (TWh) |
| RENEWABLES_SHARE_ENERGY | FLOAT | Share of renewable energy in total energy consumption (%) |
| GREENHOUSE_GAS_EMISSIONS | FLOAT | Total greenhouse gas emissions |
| CARBON_INTENSITY_ELEC | FLOAT | Carbon intensity of electricity generation |
